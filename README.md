# doodle-cursors
handmade cursors that are ugly in a good way



# ONLY AVAILABLE ON MACOS
this will require an app called "Mousecape", the links to downloads are here:

macOS Tahoe https://github.com/AdamWawrzynkowskiGF/Mousecape-TahoeSupport/releases

macOS Sequoia and under
https://mousecape.com/  (IF THIS IS BROKEN, TRY THE OTHER LINK.)

INSTALLATION GUIDE

1. download the file
2. double click on the .cape file
3. it will automatically install the cursor pack in mousecape (if it doesnt, then try again)
4. right click on the cursor pack and press “Apply”
5. done
